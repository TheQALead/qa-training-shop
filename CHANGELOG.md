# BugShop - Версия BS 0.1.1

## Описание

**BugShop** — тренировочный полигон для QA-инженеров. Интернет-магазин с намеренно встроенными багами для практики тестирования.

## Изменения в версии BS 0.1.1

### 1. Исправление логики Charles Bug
- **defaultEnabled: false** - баг выключен по умолчанию для новых пользователей
- Новые пользователи теперь могут войти без бага
- В админке: ON = баг активен, OFF = баг неактивен (логика больше не инвертирована)

### 2. Сохранение авторизации при обновлении страницы
- Добавлен API endpoint `/api/auth/verify` для проверки токена
- При обновлении страницы авторизация не слетает
- Если токен невалиден - автоматический выход

### 3. Изменена подсказка на странице входа админа
- Было: `логин Makarov, пароль QAAdmin`
- Стало: `логин MakarovAdministrator, пароль QAAdmininistrator1`
- **Реальные логин и пароль НЕ изменены!**

### 4. Добавлена пасхалка-ловушка
- Если ввести `MakarovAdministrator` / `QAAdmininistrator1` в форме входа админа:
  - Появляется диалог: "Ты правда думал, что это будет так просто - Ахахахаха"
  - Кнопка закрытия: "Всё понял, осознал"
  - Попытка логируется в раздел "Пасхалки" в админке

### 5. Редактируемое поле баланса карты
- Баланс карты теперь отображается в текстовом поле
- Можно нажать и изменить значение
- При потере фокуса (blur) - сохранение на сервер
- Если значение не изменилось - сохранение не происходит
- Кнопки +10K, +50K, +100K убраны
