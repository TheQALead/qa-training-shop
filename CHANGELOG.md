# BugShop - Версия BS 0.1.2

## Описание

**BugShop** — тренировочный полигон для QA-инженеров. Интернет-магазин с намеренно встроенными багами для практики тестирования.

---

## Изменения в версии BS 0.1.2

### 1. Критическое исправление Charles Bug для новых пользователей

**Проблема:** Фронтенд ВСЕГДА добавлял "!" к паролю, даже для новых пользователей с `charles-bug: OFF`. Из-за этого новые пользователи не могли войти с нормальным паролем.

**Решение:**
- Создан API endpoint `/api/bugs/status` - проверяет состояние багов по логину пользователя до отправки формы
- Изменён `LoginView.tsx`:
  - Добавлен запрос состояния багов при потере фокуса с поля логина (`onBlur`)
  - Символ "!" добавляется **ТОЛЬКО** если баг `charles-bug` включён для пользователя
  - Консоль теперь показывает: `Charles bug enabled: true/false`

**Как работает теперь:**

| Пользователь | Charles Bug | Пароль отправляется | Результат |
|--------------|-------------|---------------------|-----------|
| Новый | OFF (default) | `password` | ✅ Вход успешен |
| С багом | ON | `password!` | ❌ Нужен Charles |

### 2. Сохранение авторизации при обновлении страницы

**Что сделано:**
- Создан API endpoint `/api/auth/verify` - проверяет валидность токена
- При загрузке страницы проверяется токен из localStorage
- Если токен валиден - пользователь остаётся авторизованным
- Если токен невалиден или просрочен (24 часа) - автоматический выход

### 3. Изменена подсказка на странице входа админа + ловушка

**Изменения:**
- Подсказка изменена на: `логин MakarovAdministrator, пароль QAAdmininistrator1`
- **Реальные логин и пароль НЕ изменены!** (Makarov / QAAdmin)
- Если ввести фейковые данные - появляется диалог: "Ты правда думал, что это будет так просто - Ахахахаха"
- Кнопка закрытия: "Всё понял, осознал"
- Попытка входа логируется в раздел "Пасхалки" в админке

### 4. Редактируемое поле баланса карты в админке

**Изменения:**
- Баланс карты теперь отображается в текстовом поле Input
- Можно нажать на поле и изменить значение
- При потере фокуса (blur) - сохранение на сервер
- Если значение не изменилось - сохранение НЕ происходит
- Кнопки +10K, +50K, +100K **убраны**

## Функционал

### Для студентов:
- 🛒 Магазин с товарами по категориям
- 🛒 Корзина с отображением суммы в шапке
- 💳 Привязка карт
- 📦 Оформление заказов

### Для администратора:
- 👥 Управление пользователями
- 📦 Управление товарами
- 💳 Управление картами (изменение баланса)
- 🐛 Включение/выключение багов для каждого пользователя
- ⚙️ Настройка длительности PopUp уведомлений
