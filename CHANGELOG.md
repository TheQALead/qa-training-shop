# QA Training Shop - Working Version 3

## Описание версии

Ветка `working-version-3` содержит исправления ошибок и новые функции для управления картами.

## Отличия от `working-version-2`

### Исправленные ошибки:

1. **Сумма корзины всегда 0** - исправлена ошибка в ShopView.tsx: API возвращает поле `sum`, а фронтенд ожидал `buggySum`. Теперь используется правильное поле.

### Новые функции:

2. **Предупреждение при вводе данных карты** - добавлено красное предупреждение под заголовком "Новая карта":
   > ⚠️ ВНИМАНИЕ! НЕ ВВОДИТЕ СВОИ НАСТОЯЩИЕ ДАННЫЕ КАРТЫ! Это тренировочный сайт для QA. Используйте случайные данные!

3. **Управление балансом карт в админке** - новая вкладка "Карты" позволяет:
   - Просматривать все карты пользователей
   - Увеличивать баланс карт кнопками +10K, +50K, +100K
   - Видеть владельца карты и её тип (бажная/нормальная)

4. **Новый баг для поиска** - добавлен баг "Цифры в поле Владелец":
   - ID: `card-owner-numbers`
   - Поле "Владелец" принимает цифры, хотя должно принимать только буквы
   - Категория: cards, Severity: low

5. **Упрощена "Тайная кнопка"** - убрана лишняя картинка с кнопки входа в админку. Осталась только эмодзи змеи 🐍.
