# BugShop - Версия BS 0.1.3ALT

## Описание

**BugShop** — тренировочный полигон для QA-инженеров. Интернет-магазин с намеренно встроенными багами для практики тестирования.

---

## Изменения в версии BS 0.1.3ALT

### 1. Исправлена логика Charles Bug на бэкенде

**Проблема:** Сервер принимал пароль и с "!" и без - пользователь мог войти даже с "бажным" паролем.

**Решение:**
- Баг ON: сервер получает пароль с "!" → **НЕ пускает**
- Баг ON: сервер получает пароль без "!" (через Charles) → **пускает**
- Баг OFF: сервер получает пароль без "!" → **пускает**

Теперь ученик **обязан** перехватить запрос через Charles и удалить "!" для входа.

### 2. Сохранение авторизации при обновлении страницы

- Token сохраняется в localStorage
- При обновлении страницы проверяется валидность токена через `/api/auth/verify`
- Авторизация сохраняется для обычных пользователей И для админа

### 3. Кнопка "Обновить данные" в админке

- Добавлена кнопка в правом верхнем углу панели администратора
- Позволяет обновить данные без перезагрузки страницы
- Обновляет: пользователи, товары, карты, логи, баги
