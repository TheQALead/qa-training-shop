# QA Training Shop - Working Version 3.1

## Описание версии

Ветка `working-version-3.1` содержит улучшения UX и новые баги для поиска.

## Отличия от `working-version-3`

### Изменения в UI/UX:

1. **Корзина перемещена в меню** 
   - Корзина теперь находится в шапке сайта рядом с кнопкой "Выход"
   - Рядом с иконкой корзины отображается количество товаров и сумма
   - Формат: `🛒 3 (5 000 ₽)`

2. **Модальное окно оформления заказа**
   - PopUp при оформлении заказа теперь модальный и блокирует весь экран
   - Нельзя пропустить или не заметить уведомление
   - Анимация загрузки с Добби: "Добби достаёт товары со склада и упаковывает для Вас... Подожди чуток!"

3. **Убрана подсказка про адрес**
   - Удалён PopUp "Куда отправлено-то? Адрес ведь не указан..."
   - Этот PopUp подсказывал студенту баг, что недопустимо

### Исправления логики багов:

4. **Баг подсчёта суммы работает только при нескольких товарах**
   - Если в корзине 1 товар - сумма отображается верно
   - Если в корзине несколько товаров - применяется баг (+1000 или +139)

### Новые баги для поиска:

5. **Неудобное расположение кнопки "Выход" или "Корзина"**
   - ID: `uncomfortable-buttons`
   - Кнопка "Выход" расположена рядом с "Корзиной", что может привести к случайному выходу
   - Категория: ui (Интерфейс), Severity: low
   - Новая категория багов: 🎨 Интерфейс

## Запуск в Docker

```bash
docker-compose build
docker-compose up -d
```

Приложение будет доступно на порту 3000.
